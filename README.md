# SunRiver website (Netlify build)

Static site generated by `build.py` and deployed by Netlify on every push to `main`.

- **Content:** floor plans, homes for sale and Bucketlist Living posts are read at build time from the SunRiver Sanity CMS (project `ib6s13lu`, dataset `production`). Edit content in Sanity, then trigger a Netlify deploy to publish it.
- **Pages:** `sitegen/pages_main.py` (hand-built pages) and `sitegen/pages_cms.py` (CMS pages). Shared header, footer and form live in `sitegen/lib.py`.
- **Styles and scripts:** `assets/styles.css`, `assets/site.js`.
- **Media:** images and fonts from the developers' Vercel build are copied into `/media/v` during the Netlify build. CMS images load from the Sanity CDN.

Run locally: `python3 build.py` then serve `dist/` (for example `cd dist && python3 -m http.server`). Without network access it falls back to the snapshots in `data/`.
